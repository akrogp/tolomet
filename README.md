# Tolomet

> ⚠️ **This is the legacy Android app, no longer actively maintained.** Please use the new Tolomet PWA instead.

---

## 🚀 New Tolomet PWA → [tolomet.app](https://tolomet.app)

Tolomet is now a web app accessible from any device (Android, iPhone, PC). Your browser will also offer the option to install it as an app.

The PWA is in active development and will progressively incorporate all features from this Android app. Both versions can be used simultaneously during the transition.

---

## About this app

App designed for air sport lovers, especially paragliding pilots. Shows wind progress during the past hours using real-time station readings. Initially focused on Spanish stations (>1000), at current version more than 15,000 world-wide stations have also been included.

## Features not yet available in the PWA

- Widget support
- TCP socket integration (XCTrack, Alfapilot)

## Providers

Data is sourced from different meteo providers, including: Euskalmet, Aemet, FFVL, Holfuy, PiouPiou, MeteoNavarra, MeteoGalicia, Meteocat, LaRioja, RiojaSiar and Metar.
